# GIVA Diwali & Dhanteras Redesign — Working Website

Open `index.html` in a modern browser. No build step is required.

## What is implemented
- Responsive desktop and mobile landing page.
- Three auto-rotating hero banners with arrows, dots and mobile swipe.
- CSS/SVG/canvas festive animations: diya flame flicker, light-string twinkle, spark trails and firework particles.
- No AI-generated campaign imagery in the website build. Image content is taken from the supplied GIVA asset ZIP.
- GIVA campaign palette grounded in the supplied assets (`#7f055c` festive plum, `#f9f2d8` festive cream) plus the pink seen in captured GIVA CSS (`#e9718b`).
- `Lato` is used as the primary font because `font-family:Lato` appears in the captured GIVA CSS from the supplied site export. No font files are bundled.
- Structure includes: Hero, GIVA promise row, Diwali/Dhanteras collection discovery, Play & Win, Latest Collections, Pooja Essentials, Gifting Guide, Gold & Lab Diamonds Edit, Most Gifted, consultation CTA and footer.
- Consistent responsive gutter and section-spacing tokens.

## Notes
This is a front-end prototype. Live Shopify cart/search/account/checkout APIs are intentionally not faked. Category CTAs point to public GIVA collection URLs where appropriate.
